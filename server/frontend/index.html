Pi device token

此 token 只顯示這一次。請複製到對應 Pi 的 device_agent/config.yaml，不要提交或分享。

全刷／局刷設定

工作頁內容維持局刷；全刷只用於首次顯示、切換版面與下列保護週期。

靜默時段仍會同步版面與素材，但不會輸出到電子紙；結束後會先全刷一次。啟用週末靜默時，會維持最後畫面至週一早上。落在靜默內的全刷會延後。
