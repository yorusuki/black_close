epagerPi 排版編輯器

模組面板

拖曳或點擊新增到畫布；新增功能只要在 server/modules/ 加檔案並在 registry.py 註冊，這裡就會自動出現。

元件屬性

點選畫布上的元件來編輯

圖片素材庫

上傳圖片後，點縮圖套用到「目前選取的圖片元件」（要先加一個「圖片」模組元件並選取它）。

即時預覽

每 3 秒重新讀取實際合成畫面（含量化後的色彩/灰階），可以看到吉祥物動畫。

情境設定（JSON）

condition 支援 weekdays([0-6], Mon=0)、time_range(["HH:MM","HH:MM"])、is_holiday(true/false)。多筆符合時取 priority 最大者。
